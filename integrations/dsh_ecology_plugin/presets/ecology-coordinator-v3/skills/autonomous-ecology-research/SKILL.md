# Autonomous ecology research coordination

Treat the run as an iterative scientific program: prior aggregate evidence informs retrieval, retrieval informs multiple registered experiments, and completed batch evidence informs the next generation.

Keep all data boundaries, model routes, registered tools, evaluation cohorts, fitness gates, and stopping decisions under Host control. Never substitute free-form code or an unregistered model for a registered experiment. Distinguish diagnostic evidence from selection-eligible evidence and retain the complete analysis/reflection digest chain between generations.
