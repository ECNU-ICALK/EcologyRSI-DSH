# 多类型进化实施说明（0.7.15）

本次落地采用不增加默认预测次数的轮转方案。每轮仍只有一条训练主线；提示词、Skill、科学模型与执行策略依次获得实际训练机会。四个提案按冻结的类型计划生成，模型输出若全部退回参数修改会进入原有有界修复流程。小于四个提案时，所生成的类型随轮次轮转。

## 已接通的链路

1. **类型计划与选择。** 新原生运行在任务清单保存 `evolution_diversity_policy=executed_family_rotation@1`。研究与提案都校验类型分配；选择规则由应用、Director 和账本重放共用。没有该字段的历史任务继续首槽位规则。显式设为 null 可用于同预算旧策略对照。
2. **提示词。** 沿用 `author_role_directive` 的编写、修订及执行约束。已存在 authored directive 时，新多样性运行不再广告会被它覆盖的模板切换。局部编辑保留指定类型，避免提示词实验立即退化成参数训练。
3. **Skill 程序。** `author_skill_program` 一次替换候选的有界程序。程序包含 1–3 个唯一模块，每个模块有版本 ID、触发条件和最长 360 字符的 guidance。可改变模块、顺序、条件及文本。不可修改协议、工具授权、评分或数据范围。
4. **实际执行。** `observation-audit@1`、`horizon-routing@1`、`trend-check@1` 读取因果历史，计算缺测、近期变化、时距分支或趋势反转；按条件向 Planner 提供结果及 guidance。每次预测保存程序摘要、结果摘要及行为签名。执行回执证明 Host 计算及文本交付，不证明模型遵循文本。
5. **观察与复用。** 从实际工具轨迹、方法与 Skill 分支生成摘要；从过去轮次的完整、无物理违规训练修订中，按类型保留最多两个不同组件包，总大小有界。研究者和提案者可在当前父版本上复用、修订这些组件，并重新评测。档案保存探索样例，不按不同窗口原始分数排名，不改变正式冠军和晋升门槛。
6. **插件与界面。** 研究、反思、候选、局部编辑输出 schema 同步支持已接通的八个轴；进化过程显示按类型提案数、实际训练数、行为签名和探索档案数。

## 协议与成本

默认仍为 100 次训练加候选/冠军各 50 次轮末比较，约 200 次完整预测/轮。Skill 是本地计算，不增加独立模型调用；增加的策略文本可能增加 Token，用量以现有回执计量。诊断签名不跨不同 cohort 证明新颖性，也不抵消性能退化。科学评分、最终采用条件与独立认证继续由既有评测链控制。

Skill 目录与编译器升级至新身份，需要新建运行；本次不迁移或改写历史账本，不自动重启本地服务或调用远程模型。导出的 Agent 策略包随 profile 保留 Skill 程序版本。

## 验证与后续实验

回归覆盖编写/修订、非法字段与伪造目录摘要、冻结 genome 重放、条件执行、原生预测上下文和回执、研究输出类型修复、轮转及历史选择、探索档案的数据范围、插件 schema 一致性。工程通过不能替代真实数据收益实验。

2026-10-01 工程验收结果：

- `scripts/verify_delivery.sh --source-only` 通过，包括源代码语法、版本与插件内容一致性、示例进化及重放、1769 项 Python 测试（5 项按环境条件跳过）和 270 项 Node 测试。
- 最后的档案保留与评测摘要调整另行通过 50 项定向测试（其中 1 项按环境条件跳过）；其中多样性专项共 18 项。原生 API 默认配置与投影另行通过 3 项测试。
- 校验同时修正了仅有外部保留数据时的异常分类，更新了旧控制测试的能力目录与已有残差扫描策略的测试预期。
- 新插件为 `integrations/dsh_ecology_plugin/dist/ecologyrsi-dsh-evolution-plugin-0.7.15.tgz`；原有 0.7.14 包保存在同目录的 `archive/` 下，不进入当前交付包。
- 本地缺少验收所需完整 AGC 数据，未执行真实数据验收，也未启动付费模型实验。现有服务没有重启；启用本版需更新 Host 与插件并新建运行。

后续在相同模型、数据、预算和预登记随机种子上比较：旧选择策略、类型轮转、类型轮转加 Skill/探索复用。记录各轴实际执行次数、有效行为差异、同 cohort 性能与每单位 Token 收益。独立验证集不参与搜索。

共同小批筛选（例如 4×10 + 60 + 2×50）属于后续新实验协议，本版保持既有 cohort 规划。更自由的多模型工作流、任意新数值工具和按行为质量维护的多父代种群也需要单独适配与实验；本版先实现有界条件 Skill 编排及组件复用。
