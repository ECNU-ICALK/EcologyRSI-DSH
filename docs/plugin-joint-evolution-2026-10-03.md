# 插件联合进化 0.10.0 实施记录

用户授权：按“联合策略版本 → 真实同组筛选 → 执行证据与继承 → 受控计算及研究/提案策略”顺序升级。DSH Harness 固定为 0.2.0-rc.2；修改范围为本仓库插件、科学 sidecar、工作台、测试及文档。历史运行不恢复、不改合同或评分。

## 合同

- 新增独立联合进化协议，复用五臂筛选（四候选和冠军）、父子配对及轮末比较；每轮 200 次预测时点执行。数据容量预检仍强制执行，不自动缩短时间隔离或轮次。
- 新候选允许最多四个关联操作，局部修改最多两个；数值边界、真实预测来源、科学门槛保持不变。旧单轴协议继续可回放。
- 候选携带可继承的策略程序：任务提示、工具参数与调用、按时距条件计算、经验记忆和后续研究/提案建议。计算表达式使用有界解释器，禁止导入、系统访问与任意 Python 执行。
- 组合工具按内部数值调用及计算步骤计费；失败仍消耗额度。完整输入、输出和程序摘要落入现有账本。没有引用实际执行结果的策略不能获得激活证明。
- 搜索提示作为候选的待验证策略继承，不能修改评分器、评审合同、数据分区、凭据权限或预算；实际科学收益仅由固定评价器判断。

## 验证与交付

1. 联合操作编译、旧合同拒绝及回放、同组筛选和容量边界。
2. 有界计算拒绝非法语法、未来输入、非有限输出、超额调用；组合预测来自实际计算。
3. 程序继承、激活证据、失败/无效/无收益区分，以及真实本地 Harness 适配器验收。
4. 全量验证、不可变 preset 升版、交付打包和本地部署。真实模型运行必须使用新冻结合同，不能将工程验收称为预测性能提升。

参考：[Self-Harness](https://arxiv.org/html/2606.09498v3)、[HarnessBank](https://arxiv.org/html/2607.13683v2)、[GEPA](https://github.com/gepa-ai/gepa)、[DSH self-evolving](https://github.com/timwhitez/dsh-self-evolving)。只借鉴设计，本次不引入这些项目为运行依赖。


## 已完成验收（2026-10-04）

- 最终 `make verify`：1,875 项 Python、280 项 Node 全部通过，零失败、零跳过；真实 AGC 数据检查、前端 smoke 与真实 Harness 的本地模型适配器验收通过。
- 针对联合协议验证五臂筛选、父子配对、轮末封存、重启重放和预算上限；多处修改能进入正式反思并传递给下一轮搜索，旧单轴反思不能混入多操作记录。
- 数值程序实测会随参数改变输出；组合调用收费、失败收费及重放幂等经过回归。只改变指导文字保持相同计算摘要，未使用分支不能证明参数激活。
- 真实 AiCU 容量复核：683 个合格源时点，三轮需要 255 个评分起点且满足隔离；四轮需 340 个评分起点，但时间安排只能容纳三轮，因此拒绝四轮。总量充足不代表隔离后的时间安排可行。
- 新运行每次 Planner 尝试冻结 4 个预测调用额度；程序包含 1..3 次登记数值调用和一次计算，合计消耗 2..4 个额度。历史合同沿用其冻结额度。
- 原运行保留暂停状态，不转换为新协议，不改写已有预测或评分。未启动新的付费实验，工程验收不等于预测性能提升。

联合策略改变的是插件内可继承的策略及可执行计算组合。登记工具之外的新算法实现、外部依赖安装、任意代码执行以及 Harness 自身修改仍不在本版本的自动进化范围内。

- 部署网页验收发现并修复旧预检版本清单遗漏：保留 Researcher v15/v16、Planner v12/v13 的已冻结历史收据读取，新预检仍只接受当前版本。已在账本副本上逐一验证八个历史运行的概况、监控与过程投影；没有改写原账本。
