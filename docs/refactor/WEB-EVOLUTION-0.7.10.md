## 本轮发现并修复的问题

1. **独立推理副本互相覆盖检查点。** 恢复及写入权限现在按执行 scope 隔离；同 scope 的旧写入者仍被拒绝。结算只检查对应副本，恢复时完整保留原 Agent 方法、工具和参数摘要，避免结果摘要不一致。
2. **所有预测结束后轮末汇总异常。** 稳定性验证对深层只读证据还原原 JSON 表示后计算摘要，保留证据完整性和科学门槛。真实账本副本离线结算均禁止模型调用，随后正常网页恢复原运行。
3. **暂停及完成状态展示不一致。** 已完成但尚未封存的副本仍计入进度；暂停及终态不显示运行中 ETA。初筛淘汰、正式阶段完成、未提供的详细证据均按真实状态显示。轮末知识归因缺省、初始对照未认证、历史批次的后续比较和研究前诊断明确各自含义。

4. **重启后的大账本重复重建。** 反思方向缺少缓存类型登记，导致完整状态快照无法保存，普通读取反复触发事件重放与统计门槛计算。补齐显式类型白名单，并将已完成运行各工作区、事件和样本分页保存为独立、按源码与账本版本校验的快照；运行中的动态状态不从终态快照读取。容量检查与样本预览并发首次加载同一数据集时，只执行一次解析，避免重复读取和计算。分页快照每个运行最多保留 64 份且总量不超过 32 MiB，单页上限 16 MiB，过大内容按需读取。

两次恢复均保持已有账本事件逐条一致，没有重做已完成的预测。第二次恢复只新增轮末反思调用，预测与数值工具调用为零。原实验以 0.7.9 创建，修复只调整检查点、序列化和只读展示，保留其冻结模型、提示词、数据、评分、预算及运行身份；结束后才统一升版为 0.7.10。
