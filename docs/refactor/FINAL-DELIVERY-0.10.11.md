# EcologyRSI-DSH 0.10.11 交付说明

本版为本地研究交付候选版，固定适配 DeepSeek Harness 0.2.0-rc.2，未签名。发布包包含 Python wheel、源码包、DSH 插件、完整源码与安装文档。实际验收结果、源码快照身份和产物 SHA-256 随交付目录的 `ACCEPTANCE.json`、`PROVENANCE.json` 和 `SHA256SUMS` 提供。

## 本次最终审查与修复

| 审查项 | 处理结果 |
|---|---|
| 策略与评审强制不同模型 | 移除前后端同 ID 拒绝及默认自动排除；允许一个具备两个角色权限的模型同时承担两种角色 |
| 角色隔离与恢复 | 保留逐角色权限检查、独立原生会话、role/preset/schema 绑定、四角色预检及历史冻结合同；同模型不意味着统计独立 |

| 新模型目录 | 可登记 `deepseek-v4.1-flash-1017`；本机使用 PJLab 连接。接收方须自行配置服务地址与凭据，并在其部署中通过真实预检 |
| 文档与源码漏项 | 补入 `ruff.toml`、推理配置说明，修正旧的不同模型限制与历史运行状态 |
| wheel 校验 | 拒绝敏感路径、重复成员和非预期内容，并将交付内容与选定源码核对 |
| 完整包内嵌产物 | 内嵌 wheel、sdist、原生插件须与外部已校验的同名产物一致，不能只信任包内自带摘要 |

## 验收方法

交付源码从当前工作区的公开文件白名单复制到独立目录，保留逐文件 SHA-256。在该目录创建本地快照提交后执行 `make release`，其流程包括源码合同、确定性演示与重放、Python 全量回归、Node 与前端回归、固定真实 Harness 加本地模型替身验收、构建以及干净虚拟环境安装冒烟。另运行 `make lint` 和 `uv lock --check`。

测试使用已准备的 AGC 黄瓜与番茄数据；原始数据不随源码分发。工程测试不调用接收方远程模型。完整包内 `BUILD-INFO.json` 的 commit 是本地交付快照身份，**不是原仓库已提交或已推送的发布提交**。原仓库的既有未提交修改不会因交付构建而清除。

以同目录 `ACCEPTANCE.json` 的实际退出码、测试数量、跳过项和安装结果作为本版验收凭据。本说明不把前版测试数量当作本版检查结果。SHA256SUMS 用于发现内容变化，不构成发行方数字签名。

## 已有真实进化证据

独立冻结于 **0.10.8** 的 U 运行已完成连续两轮：400 次实际起点执行、3,600 格预测、170 个不同环境起点；18 组评分独立重算一致。两轮均按原门槛保留种子，未证明预测收益，也未完成独立科学认证。600 是包含未执行条件复核预留的预算上限；时间相关的起点不等于独立重复试验。

该运行保留了 20 次已恢复供应商重试及 2 次 critic 子任务失败，不能解释为全程零故障。15 次 Host 有界纠错在原 child 中完成；“拒绝后补工具”的特殊路径在 U 的真实覆盖仍为零，其证据来自本地回环与历史轨迹回放。以上历史运行不重新标记为 0.10.11 实测。

## 接收与启动

1. 校验交付目录 `SHA256SUMS`，解压 `ecologyrsi-dsh-0.10.11-delivery.tar.gz`。
2. 按[根 README](../../README.md#快速启动)准备 Python 3.10+、固定 Harness、独立 DSH_HOME 和真实数据；安装内附 wheel 或源码。
3. 配置自己的模型路由与服务端凭据，同时显式设置 Python 读取的 settings/credentials 路径。可将同一可用连接分配给策略和评审。
4. 启动 8777 Host 与 8848 网页服务，核对版本及模型目录。新建运行必须完成其真实四角色预检；不要将“已登记模型”理解为上游当前可用或已验证科学效果。
5. 首次运行先使用容量允许的有限轮数；已有实验必须保留冻结身份，升级前备份账本和配置，不能通过放宽门槛制造进化成功。

交付目录另提供 `source-snapshot.bundle`，用于重建与 `BUILD-INFO.json` 一致的本地源码提交。需要复核产物时，可 `git clone source-snapshot.bundle review-source`，将交付目录中的 wheel、sdist、插件、完整包、`BUILD-INFO.json` 与 `SHA256SUMS` 复制到 `review-source/dist/`，然后在该目录执行 `make verify-artifacts`。直接解压的源码包不携带 `.git`，安装和使用无需 Git，但完整来源校验需要此快照仓库。

## 交付边界

这是本地单进程/SQLite 研究系统，非生产多租户服务；没有官方市场签名，不执行任意生成代码，不控制真实设备。仅验证历史时序预测，未证明因果控制收益或跨地点、跨季节泛化。独立验证与最终测试须另用隔离数据和预先批准的预算。

本机运行账本、原始模型会话、凭据、私有连接配置与原始数据不进入交付包。新增模型的远程可用性属于部署验收，不通过跳过预检或关闭权限检查来替代。
