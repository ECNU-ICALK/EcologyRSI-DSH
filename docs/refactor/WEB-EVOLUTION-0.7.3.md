# 0.7.3 网页运行预算与执行故障修复

延续 [0.7.2 网页实跑](WEB-EVOLUTION-0.7.2.md)。此前修复的零残差问题在第三次运行中未再出现：270 次数值工具调用全部成功。但 API 创建仍冻结旧的 4,096-token 预测预算，而适配器默认及此前独立诊断采用 8,192。六个已结算时点均在最终预测提交前耗尽额度，尚无成功预测。该运行从正常网页停止，保留失败及取消的独立记录。

## 本次修复

- 运行创建和原生预测适配器共用不可变预算定义：Planner/修正各 8,192 tokens，按需 Critic 2,048；新运行将其写入清单，既有运行不被暗改。
- 明确的输出额度耗尽、工具协议不支持提升为执行故障，不生成用于比较模型的惩罚预测值。运行级准入阻断等待和后续时点，现有故障收尾负责关闭运行；普通数值工具错误仍允许 Agent 选择替代能力。
- `ecology-sample-planner-v8` 明确单时点推理目标：六次工具调用是上限，不要求耗尽；避免用不同工具名重复计算同模型同参数，保留完整预测向量的输出空间。
- 更新网页契约验收和交付脚本，移除对已删除的预测器选择控件及过期预设目录的依赖；锁文件版本同步为 0.7.3。

## 验证记录

- Python 117 个测试模块、1,505 项测试，真实数据启用，无跳过。首轮发现交付 shell 脚本仍引用旧预设目录；修复后完整重跑该模块 42 项通过，其余模块首轮通过。
- DSH 插件 218 项测试通过。新增回归实际覆盖：工具已调用后预算错误向上传播且不落库惩罚分；同运行等待中的多个候选被拒绝准入；新运行不受旧运行故障影响。HTTP 集成检查新运行冻结 8,192-token 预算。
- 网页创建契约测试通过：提交 `model_during_run@1`，不指定固定预测器或评测器；预检失败不创建运行。该项使用拦截响应，只用于表单契约，不算真实模型验收。
- 独立的真实网页测试通过 DSH 侧栏进入，真实模型预检后创建第四次运行 `run:cea124b4-b712-45de-8c7a-f552c7fd62ad`。最终只有 1 个时点、9 项预测完整成功；其后仍出现输出额度耗尽及批量超时，已从网页取消。该结果暴露故障在候选层被吞掉，以及供应商默认推理模式成本过高的问题，继续在 0.7.4 修复。

本次真实运行使用 AGC 2018 AiCU，GLM 5.2 策略、Kimi K3 按需独立评审。按冻结配置开展一代四候选；科学评测、正式留出及发布门禁保持独立。工程测试通过不替代真实运行和科学验证。
