## 仍需解决的预测问题

选中的搜索版本在轮末留出集上的 1h 温度、湿度和 CO₂ RMSE 分别比冻结基线降低约 17.4%、3.8%、3.4%。6h 的三个目标均弱于冻结基线：温度误差增加约 285.1%，湿度约 44.1%，CO₂ 约 43.7%。基线在 training-fit 内按单元选择 persistence 或 seasonal-24h，因此“优于旧种子”不能代替“优于合适基线”。

下一轮应优先在 training-fit 内滚动检验 6h 残差缩放、正则化与历史窗口，一次改变一个因素；同时观察温度 24h、湿度 1h/6h 和 CO₂ 24h 的退步。先完成拟合分区内诊断，再使用新的时间隔离队列及未参与搜索的验证材料，不能复用本轮留出结果来调参后宣称独立验证。

## 已修复的工程问题

- 工具调用被输出为普通文本、输出预算耗尽有独立错误码，避免确定性故障的相同请求重试。
- 研究与预检失败保留实际阶段；提案获得宿主计算的单步参数范围。
- 配对检查点与最终评分共用版本解析规则，支持旧冠军和新候选分别恢复与原子封存，同时拒绝串用版本、批次和数据。
- 巡检器以完成工作计量进度，排除维修暂停时间；持续运行中重启巡检或仅用量增长不会重置停滞时钟。总截止时间与 token 阈值保持优先。
- 修复完整一代结束后代数推进引起的 67% 进度回退、已封存筛选证据被误判中止，以及轮末共享建议评审未完成的误报；按统一单位汇总筛选、配对更新和留出评分项，避免重复计数。
- 源码发行包显式包含最终聚合 JSON；不包含运行账本或原始评测记录。
- 研究和轮末反思均收到宿主模型事实：三种 ridge 变体都分别拟合各目标/时距的系数，残差尺度由 genome 固定；相同历史和特征配置下改变尺度布局不增加拟合系数。此补充只影响后续请求，不改写本轮反思记录。

GLM 的轮末反思已完成：角色为 `generation-judge`，阶段为 `generation.reflect`，两次语义契约尝试后落账，给出 5 条经验和 4 个后续方向。这是独立模型的建议性评审；最终选择与停止由宿主决定。原反思中仍有过强机制解释及尺度/系数混淆，新增事实上下文已通过回归验证，但不保证模型自由文本全部正确。
