# 研究综合阶段约束与输入诊断

针对两次真实研究综合耗尽 8,192 输出预算的故障，本次独立诊断检查了已有输入、JSON schema、`validate_research_synthesis` 及单步可实现性校验。没有新增模型调用、创建真实候选、读取标签或修改历史账本。

聚合证据与完整合成输出见 [RESEARCH-SYNTHESIS-CONTRACT-0.3.59.json](RESEARCH-SYNTHESIS-CONTRACT-0.3.59.json)。该文件中的四方向是离线构造的契约样例，不是模型生成的科学研究结果。

## 四方向约束可满足

全零 aligned seed 的有效数值轴是 `residual_scale_1h`、`residual_scale_6h` 和 `residual_scale_24h`。Host 要求方向 ID 与假设互异，并验证可实现不同的候选行为；没有要求每个方向都使用不同参数轴。

样例使用四个假设：检验 1h 温度修正、6h 湿度修正、24h CO₂ 修正以及 1h 湿度修正。每个方向都使用单个 horizon scale，均声明跨目标副作用和完整矩阵复核。前后两个 1h 假设复用同一轴，由候选 proposer 在兄弟候选避让约束下选择不同的合法值；研究文本没有指定数值。按真实源运行冻结的任务和 canonical seed 验证，四个方向均通过，四个 witness behavior digest 互异。

样例完整 JSON 为 **2,283 字符／UTF-8 字节**。这证明结构化报告本身不需要接近 8K 输出预算。样例中的 cell 弱点被明确描述为待验证的不确定性，没有伪造已观察到的缺陷。

指令模板轴只适用于已有 Planner 过程故障；不应为了填满四个槽位而虚构过程故障。新上下文明确“不同方向不等于不同轴”，同时把数值实验与指令可靠性实验的成功指标分开。代码仍拒绝相同假设、全零状态下无数值作用的 history/alpha 单步修改以及其他不合法操作。

进一步检查发现，原 proposer 只看到兄弟行为的哈希，重复后的新子会话也看不到被拒绝的参数值。同轴方向因此可能反复猜中同一常用值。新策略会显示该目标已被相同 parent 程序占用的具体参数值、来源槽位和行为摘要；Host 先按相同单操作重建行为并精确匹配，避免把不同 Agent 程序下的数值相同误判为禁用。重复反馈带回该次操作与改用另一个合法值的说明。原重复行为校验仍然生效，旧策略输入不变。

## 输入热点与实际压缩

对真实 GLM 运行 `run:d1f998d8-4cb6-4843-ac73-e807be23c151` 的综合阶段输入进行确定性投影：

| 项目 | 原格式 | 新格式 |
| --- | ---: | ---: |
| context 字符 | 34,447 | 32,548 |
| context UTF-8 字节 | 35,639 | 33,616 |
| 完整证据卡 | 13 | 13 |

字符数降低约 5.5%，字节数降低约 5.7%。新格式已经计入新增的真实单步边界表、冻结执行策略及短报告约束，因此这不是单纯删除字段前后的不完整对比。

最大部分为证据卡：14,560 字符，其中 summary 正文占 8,326 字符。所有证据卡、证据 ID、来源属性及 metadata-only 限制均完整保留。压缩主要来自重复 genome 运行身份、重复引用目录、重复查询、重复科学参数活动说明及可由目标和时距列表恢复的笛卡尔矩阵展开。完整科学参数和 Agent 程序仍在输入中；失败信息、历史适用范围、证据不足提示均保留。单步边界与注册上下界按 Host 实际函数生成，以共享列名的表格表达。

源上下文摘要、真实 parent genome digest 和冻结策略包含在新 context 的身份链中；原始 canonical seed 及其任务身份仍由账本保留。报告中输入尺寸按捕获的 JSON 计算，JavaScript 对整数浮点数的字符串规范化不被当作新的 genome 身份；parent 身份另外与账本 canonical JSON 核验。

## 新运行执行策略

仅当任务显式冻结 `research_execution_policy` 时启用新综合格式及 16,384 最大输出预算。无此策略的旧运行仍使用原宽格式、原报告规则与 8,192 预算，不重写事件。

输出 schema 版本及字段保持不变。新运行要求 summary 不超过 1,200 字符、最多八条引用证据，以及简短方向说明；Python 在原科学校验后强制这些限制。DSH 原生接口拒绝 `maxLength`／`maxItems` 等不支持的关键词，阶段 Schema 在完成专门化后统一投影到支持的子集，文字描述保留长度要求；最终限制仍由 Host 校验。已经使用本机真实 DSH 校验器覆盖全部阶段及新综合变体。

这次修复排除了硬不可满足的四方向契约，并缩短必要输出。16K 预算提供更多推理及最终 JSON 空间，**不构成下一次真实模型一定完成的保证**；后续应以真实结构化返回、候选、评分和进化闭环判断效果。

验证：研究上下文、候选方向、零修正行为、产物修订身份及严格 shadow replay 共 56 项回归通过。新增内存原生流程先让第四个同轴候选故意重复倍率 0.1，再确认新子请求能看到具体拒绝值并修复为 0.05；新旧策略分别验证。还覆盖四方向可实现性、证据及边界保留，以及短报告限制。全部使用本地模拟或只读已有输入。
