# 0.3.59 网页请求与展示一致性复核

本轮从真实网页操作发现并修复了表单入口缺陷：可见的预测方案没有被提交处理器传入创建请求，导致界面选择基线对齐方案时，后台仍绑定旧预测器，也未启用相应搜索门槛与模型预检。现在预测器、自动绑定评测器、搜索门槛和预检要求贯穿真实表单提交边界。

## 已修复问题

- 目录刷新保留用户显式选择的可用、兼容预测方案；默认方案只用于首次选择或无效选择的替代。
- 预测方案与评测器必须同时可用且兼容；自主模式不能绕过这项检查。
- 当前参数的数据容量核验完成前，按钮明确显示等待。旧参数的迟到响应不能覆盖新参数结果或提前允许提交。
- 预检、创建提交和创建结果核对分别显示。创建新运行时，流程及顶部状态不会混入上一运行的候选、事件和暂停状态。
- 当前 DSH 研究活动可在尚无候选记录时显示“模型执行中”，数值进度仍以服务端证据为准；终态与暂停不被旧活动重新显示为运行。
- 新搜索门槛使用“稳健搜索规则”标签，参数说明、局部比较和轮末选择口径一致。
- 展示持久模型预检审计、两角色身份与回执校验值。历史未保存回执与当前已核验分别说明；预检不等于科学认证。
- 待复核记录显示具体修订、原因与下一步证据要求，不暗示会自动调用模型或重用已观察数据。
- 未评测的空分数不再形成伪造的零分轨迹；空基线误差不再误标为零并错误显示预测退化。
- 长终态标签在窄屏内换行，修复 390 像素屏幕上页面被撑到 527 像素的问题。
- 运行配置显示实际冻结的研究执行策略：新协议的综合单次输出上限为 16,384 tokens，历史缺少该策略字段的运行不补写新值。
- 训练产物区分别显示原始提案来源与实际 revision，并展示实际训练参数；历史 v1 不宣称通过新版本封套核验，详见[产物身份修复](ARTIFACT-REVISION-IDENTITY-0.3.59.md)。
- 候选详情只读取自身 scope 的样本进度，不再把全运行的 1,195 起点分母套到单候选的 64 起点初筛上。
- 历史运行完整详情与事件尾部统一使用既有 30 秒数据读取预算；8 秒默认超时导致的切换失败已用只读响应延迟复现并修复。
- 首次加载的运行摘要列表同样使用 30 秒数据读取预算；实测忙时列表约 11.3 秒而目录约 2.2 秒，旧的列表 8 秒超时会使已经可用的目录也被初始化失败路径清空。
- 模型活动按阶段汇总尚未收到终态回执的任务数量，使一个候选的局部修改不会被另一个候选的新样本调用遮盖；这些数量不是 provider 物理并发快照，不包含 Session 标识或模型上下文。
- 配对批次尚未封存比较结果时，版本详情仍显示实际待比较版本及已生成的下一挑战版本，并明确尚未据此晋升；创建 R1 与保留 R1 分别说明。

## 验证

`node plugins/ecology_evolution/test/smoke.mjs` 覆盖真实 `bindEvents → submit → createRun → HTTP 请求` 边界、预检失败禁止创建、容量响应竞态、缺失值与历史状态。

`scripts/verify_browser_contract.mjs` 提供浏览器验证入口，需 Node.js、可运行的服务、至少两个已配置模型角色、Playwright 及系统 Chrome。Playwright 可由环境预装或通过 `NODE_PATH` 指向已安装它的 `node_modules` 目录：

```sh
node scripts/verify_browser_contract.mjs \
  --url http://127.0.0.1:8848/plugins/ecology/evolution/ \
  --output-dir /tmp/ecologyrsi-browser-review
```

可用 `--browser` 指定 Chrome 可执行文件；否则使用系统 Chrome。Playwright 可以通过项目依赖或 `NODE_PATH` 提供。

例如依赖位于单独目录时，在上述命令前设置 `NODE_PATH=/absolute/path/to/node_modules`。脚本没有 `--help` 模式，受支持的参数为 `--url`、`--output-dir`、`--browser`、`--selection-read-delay-ms` 和 `--initial-list-read-delay-ms`。两个延迟参数默认 0；设为 9000 可分别只延迟历史运行或首次运行列表的 GET 响应，核验忙时读取，不改变服务中的运行状态。

脚本读取已有运行并检查 1480、390 像素下的设置、参数、过程和候选页；只有存在已完成运行时才覆盖历史终态。创建与模型预检请求全部由浏览器内的本地测试响应拦截，不会启动真实进化或调用模型；意外写请求被阻止。输出 `result.json` 和截图，包括具体步骤、请求耗时及失败时的页面状态。导航栏与表格自身的水平滚动属于预期行为，全页面溢出和容器之外的操作按钮裁切会使检查失败。

研究策略额外使用本地创建响应 fixture，在两个宽度下展开运行配置并检查实际显示的输出上限和重试规则。这是页面合同回归，不作为模型已按新策略执行成功的证据。

本轮上述测试通过，真实新运行的预检审计与研究执行状态也已只读核对。网页入口及展示通过验证，不代表候选已获得独立最终验证或科学认证。
