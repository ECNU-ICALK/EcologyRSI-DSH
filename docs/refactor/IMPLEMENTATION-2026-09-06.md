## 1. 已落地的范围

| 方向 | 实际改动 | 接入与边界 |
| --- | --- | --- |

| C 科学计算 | 原生温室岭回归通过 NativeBatchBackend 执行；提前冻结 EvaluationContext，绑定实际小时戳、case 网格、单位、分区、基线、尺度、指标和证据等级 | 接入主评测链。原生 bounded RMSE skill 与实验内核 normalized MAE 保持不同合同，不混排分数 |

| F 查询与产品 | 有状态增量 reducer；版本化、可丢弃 JSON 快照；持久化运行摘要；默认 50、最大 200 的游标分页；工作台加载更早运行；定时刷新摘要与进度 | 已接入主查询及工作台。损坏/旧版缓存回退事件账本；完整详情按需读取；保留全量回放校验 |

原生主链现在为：工作台 / CLI → 公共装配与应用执行 → 数值或现有 DSH 执行 → 原生宿主评测与 director → 原生事件账本 → 增量查询。v2 搜索保持独立实验账本，不能更新主工作台运行的当前版本。

本次没有把整个 kernel 仓库作为新产品覆盖进来，也没有为迁移后的 API 模块保留转发副本。尚未失去调用者的原生实现继续保留。

- 原预览数据库的两个运行，在隔离备份上完成持久快照恢复与全量回放一致性检查。证据：`preview-checkpoint-parity.json`。

## 3. 策略实验的实际结论

首轮 120 小时任务的独立块数不足，门禁正确返回 `inconclusive`。保留该结果，新增启动前块数检查，并以 240 小时任务重新执行。

正式工程对照使用 3 个训练种子、3 个未见验证种子、5 种策略，每任务每策略 4 次候选拟合/预测调用，包含初始 persistence 基线。候选、origin 和 prediction-cell 预算完全一致；拟合工作量与实际运行时间另行报告。

| 策略 | 未见合成任务平均最终 loss（越低越好） |
| --- | ---: |
| grid | 0.0334243 |
| random | 0.0287414 |
| guided | 0.0273398 |
| memory | 0.0273398 |
| adaptive | 0.0334243 |

该实验没有证明记忆优于 guided，也没有证明 adaptive 策略自我改进。不同随机种子的同一合成生成器不能替代真实温室、季节或任务的独立策略验证。完整计划、冻结选择和逐实验消耗见 `policy-study-full/`。

## 5. 仍需后续切换验证的部分

此次完成了上述具体调用链和工程验证，不把整个长期方案标记为全部完成：

1. 新 DSH 适配器还需要真实 DSH 外部模型场景的断链、重启和取消验收，随后才能替代原生执行入口。
2. 新研究策略及结构化记忆尚未替换主 DSH 研究器，需要真实任务的等预算外层验证；独立 v2 实验不能作为生产自动切换依据。
3. director、generation 编排和原生研究模块仍有较大的领域实现；后续继续按生命周期、实验结果接受和科学决策拆分，统一尚未收口的写入用例。
4. 正式确认需要项目级原始行/时间区间暴露管理；当前未开放确认/发布接口。作物、根区、干预与长期世界模型能力也不属于本次数值重构的已实现能力。
