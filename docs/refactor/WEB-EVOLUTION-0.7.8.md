# 0.7.8 网页实跑与稳定性修复

本轮使用正常 DSH 网页入口、真实 AGC 数据和原生 Agent 工具调用；未拦截网页请求或替换模型返回值。后端与 DSH 预览地址分别为 8879 和 8851。

## 已确认并修复的问题

- Agent 预测的样本 ID 和 wave_digest 进入动态输出约束，拼写错误可在同一个 Agent 子任务内被发现，而不是执行完后才被宿主拒绝。
- 并发执行器遇到异常后停止补充任务，但继续验证、保存已经执行完成的其他起点。原始异常在清理完成后向上传递，恢复不再重复这些已保存结果。
- 单个样本的输出额度耗尽记为失败，不用相同额度重试；保留失败惩罚和覆盖率约束，不再因一次评审输出不足而取消所有候选。工具协议不受支持等运行环境故障仍由运行级控制处理。
- 数值工具响应提供剩余调用次数，提醒 Agent 在六次调用上限内完成预测。服务端的调用上限和引用证据核验继续生效。
- 子任务默认启动间隔由 3 秒调整到 6 秒；供应商反馈仍可进一步退避，原有并发上限不变。

## 实跑证据与边界

0.7.7 的第九轮完成 89 个预测 Agent 输出、5 个独立评审输出和 424 次数值工具调用，其中 423 次工具成功。因并发异常清理未发布后续完成结果，最终仅 36 个起点（324 个预测单元）进入评分，全部具有完整 Agent 链路，没有宿主代预测。运行还暴露样本 ID 抄写错误、调用超限、供应商 RPM 限流及一次评审输出耗尽；该轮已在网页取消并保留事件记录。

0.7.8 第十次网页运行通过真实预检，完成四个候选生成和首批 11 个起点（99 个评分单元），69 次数值工具调用均成功。观察窗口内未出现子任务错误、样本身份拒绝或限流；之后为调整独立评审推理档位在网页停止。此时尚不能据此声称完成整轮进化或证明预测质量提升。完整科学验收仍需筛选、正式评测、独立保留集及重复推理阶段的实际结果。
