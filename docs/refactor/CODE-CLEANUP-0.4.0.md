# 0.4.0 代码清理与主链收敛

本版按当前网页与 CLI 实际使用的运行链路清理代码，不为已删除的实验入口保留转发或兼容包装。

## 清理范围

| 原有实现 | 处理 |
|---|---|
| `src/ecologyrsi_kernel/` | 删除独立实验运行时、账本、数值演示和搜索控制器；其中共用的规范身份工具归入原生 `core/identity.py` |
| `src/ecologyrsi_dsh/evolution_lab/` 与 `plugins/ai_evolution_lab/` | 删除未接入工作台的另一套实验台及 CLI |
| `src/ecologyrsi_dsh/adapters/` | 删除未被原生运行时使用的适配器和独立请求存储 |
| `src/ecologyrsi_dsh/research_kernel/` | 删除未使用的合同与研究记忆；原生流程使用的诊断、假设合同归入 `core/research.py`，复用统一身份计算 |
| `application/v2.py`、`application/policy_study.py` | 删除对应命令、示例、工具和冗余测试 |
| 网页样本接口兼容分支 | 只接受当前平铺响应；核验运行、候选和分页，删除旧响应猜测与接口失败时的摘要回退 |
| 过时迁移计划 | 删除六份已失效计划；历史实验报告保留并明确历史属性 |

按本轮开始前的源码快照计算，生产代码从 **232 个文件、119,262 行** 收敛至 **182 个文件、114,689 行**，净减少 **50 个文件、4,573 行**。范围为 Python/JavaScript/SQL 生产源码与运行脚本，不包含测试、文档、二进制包或之前未提交改动。迁回主项目的共用模块已计入新增量，没有把搬迁误算成全部删除。

`tests/refactor/` 中仍验证原生行为的测试迁入主测试目录，包括并发提交、冻结合同、科学资格、使用量、检查点和研究诊断；随独立实验运行时删除的测试不再计入当前验收数量。

## 当前架构与接口

网页和 CLI 通过 `application/runtime.py` 装配同一应用服务，由 `core/` 状态机决定保留、晋级和终止，向同一运行事件账本写入事实。DSH 执行、科学评测与只读投影保留各自职责。确定性演示同样经过原生闭环，用于工程回归。

- 移除 `ecologyrsi-dsh v2`、`ecologyrsi-dsh policy-study`、`ecologyrsi-ai-evolve`，不提供旧入口别名。
- 原生运行中使用的只读 JSON 容器仍参与规范身份计算，冻结前后的内容身份一致。
- 样本读取仅接受 `ecologyrsi-dsh.browser-sample-results/1`；无样本归档的终态候选显示 `unavailable`，HTTP 失败显示错误和重试。显式 `?demo=1` 继续标明演示。
- 生产评测执行器、科学比较资格与冻结数据合同仍是当前运行所需功能；本轮没有为减少行数而删减这些检查。
- 0.3.60 的分区加载、请求合并、有界缓存、历史分页和完整轨迹按需读取继续保留。
