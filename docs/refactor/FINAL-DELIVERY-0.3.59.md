# 0.3.59 整体框架与交付结论

本版沿用现有工作台、接口和账本，逐步迁入参考项目中适用的设计。交付定位是可审计、可恢复的本地研究闭环。原网页实验已完成，终态、源码和交付产物分别形成可核对的验收证据。

## 大框架

系统保留一条正式进化主线：冻结合同 → 调研与候选生成 → 同窗筛选 → 局部配对 → 共同留出 → 独立评审 → 宿主决定 → 反思与封存。

| 职责 | 归属与约束 |
| --- | --- |
| 提出研究方向和修改 | 模型提出结构化建议，范围限于登记的算法、参数和工具 |
| 产生可比较的证据 | 数值内核负责训练、预测、固定数据边界和科学评分 |
| 决定采用哪个版本 | 宿主状态机统一核对资格、统计门槛与真实评审，模型不能改分数或自行晋级 |
| 运行与恢复 | 执行层共享供应商并发与限流反馈，事件账本保留事实，检查点作为可重建缓存 |
| 页面和交付 | 页面读取服务端结论；源码、实际测试、安装包和实验结果分别核对身份 |

参考内核使用独立实验入口，不能与网页主链并行写入冠军。这次没有整体覆盖原项目，也没有把另一套内核接成第二条决策通道。

## 本版解决的主要问题

1. **配置与实际执行脱节**：表单、预检、冻结任务、实际修订和产物现在使用可核对的身份。恢复沿用原实验，不重新生成研究计划或改写既有评分。
2. **科学收益与执行成功混用**：配对双方都必须具备完整执行证据。执行失败造成的分差不能认证为科学改进，没有合格改进时保留原版本。
3. **最终决策缺少真实评审**：补齐Top-2分支的独立评审关口，分别保留科学评分与模型意见；缺失或拒绝的评审阻止采用，接受也不能越过科学门槛。
4. **执行压力反馈不完整**：宿主结算按会话身份索引，减少并发回执反复扫描全历史；供应商RPM限流触发共享降速，取消、排空和恢复使用明确的生命周期。

详细缺陷和过程证据见 [网页实测记录](WEB-DELIVERY-0.3.59.md)，不作为主架构的阅读前提。

## 最终实验结果

原网页实验 `run:121a3305-e5fa-461c-ab0c-7db6a4e9ed09` 已完整结束：研究生成4个候选，完成筛选、两个局部优化通道、三组共同留出、两份真实独立模型评审和反思，最终状态通过完整事件重放核对。

计划并实际归档1195次完整预测、10755格评分，其中失败4次完整预测（36格）。每个预测原点的9格互相依赖，不能当作9次独立实验。共同留出结果如下，两个模型方案均保持各自R0修订：

| 最终对照方案 | 原始综合分数 | 成功原点 | 独立评审 |
| --- | ---: | ---: | --- |
| 入围方案1（1h修正0.05） | -0.00100373 | 168/169 | 拒绝 |
| 入围方案2（6h修正0.075） | -0.00534146 | 169/169 | 拒绝 |
| 原基准 | 0.00000000 | 169/169 | 对照组 |

**没有候选满足本轮采用门槛，宿主保留原基准；严格认证也未选出新版本。** 第一个局部挑战曾因原版本执行失败而出现较大分差，配对资格关口正确拒绝认证；第二个局部修改因同窗表现下降而被拒绝。完整运行并不代表每轮必然改善。

第二入围方案的169个原点、1521格数值预测和169条原生工具回执完整复现，最大预测差为0；评分差仅浮点舍入量级。第一方案含失败，未删去失败后将其冒充完整回放。

本轮报告用量为35,811,535 token，包含缓存读取且历史取消流计量可能不完整，不代表货币费用。睡眠、暂停恢复和监控截止顺延均保留在证据中；不得把全程表述为原180分钟墙钟内完成。

终态、科学门禁、评审与产物身份见 [实验结果](WEB-EVOLUTION-RESULTS-0.3.59.json)，数值一致性见 [封存回放](WEB-NUMERICAL-REPLAY-0.3.59.json)。历史10133条账本记录与原备份逐条一致。

## 后续优化顺序

1. **先降低执行成本**：为新实验建立独立版本的批次数值执行协议。模型按批次提出策略和评审，宿主批量执行已冻结的数值模型，继续保留逐时点证据。先做封存结果等价回放和有界真实对照，再替换当前主链。
2. **再验证科学收益**：用训练段诊断选择有实际作用的修改空间；锁定候选后进行跨序列、等预算的独立验证。不能通过放松门槛或反复查看同一留出结果宣称稳定收益。
3. **按边界继续拆分实现**：围绕评测、轨迹编排和只读投影逐项拆分较大的模块，保持唯一决策入口。暂不扩展任意代码生成、分布式执行或新的控制场景。

## 交付边界

当前适用于单机、受控访问的离线研究。它验证已登记温室模型的有界进化流程，不保证每轮都有改进，也未完成独立validation/final_test或跨温室泛化验证。模型服务仍可能限流或不可用，失败会保留在实验结论中。长运行还观察到原生进程较高的序列化负载，逐时点会话成本仍是主要性能约束，当前不作高吞吐承诺。

暂停时，尚未封存的留出阶段汇总进度可能暂时回退；恢复后继续按已结算记录处理，原始评分不丢失。这个显示局限保留在后续维护范围，不能据此重做已完成实验。
