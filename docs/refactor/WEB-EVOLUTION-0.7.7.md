# 0.7.7 网页真实迭代验收

延续 0.7.3–0.7.6 的真实网页验证。已修复结构化输出修正、零残差缓存工具、运行预算及进度一致性、运行级故障取消、原生推理配置指纹、研究推荐长度和旧运行列表加载。

第八次运行证明自然语言关键词门禁仍会把“当前残差系数为零”误判成变更指令。0.7.7 删除这组冗余门禁，研究原文只用于审阅和回溯；候选提案仅接收冻结的 mutation_axis / mutation_target / mutation_direction / evidence_refs。参数值由有界提案生成，单一操作、受信组件、参数边界、方向、行为去重、样本分区及统计门禁继续由 Host 强制执行。用于人类明确干预的解析规则移到 interventions 模块保留。

研究预设升级为 ecology-researcher-v12，样本预测预设保持 ecology-sample-planner-v8。已验证独立 GLM 配置实际关闭额外推理流，搜索约 5–7 秒、研究约 20–32 秒；配置示例见 [原生推理配置](../../examples/dsh-native-inference.md)。

第九次已完成 89 个预测 Agent 输出和 5 个独立评审，但暴露了结果清理丢弃、样本 ID 抄写、限流和评审输出不足等问题，已停止并保留记录。0.7.7 全量 117 模块、1506 项 Python 测试及 218 项插件测试通过，真实数据启用且无跳过。后续修复与实跑结果见 [0.7.9 验证记录](WEB-EVOLUTION-0.7.9.md)。
