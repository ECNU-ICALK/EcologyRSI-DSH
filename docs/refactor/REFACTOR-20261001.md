# 0.8.0 重构记录（2026-10-01）

## 已落地的结构

- `integrations/dsh_ecology_plugin/presets/preset-manifest.json`：统一角色、阶段、工具权限、schema 和模型探针身份；Python、Node 与安装器读取同一清单，跨语言及资源一致性纳入测试。
- `evolution/mutation_specs.py`：统一变异操作的字段、方向、角色边界、目标及冲突路径；具体操作继续执行科学边界、信赖域、工具授权和语法校验。
- `application/generation_execution.py` 中的 `EvaluationSession`：普通候选、初筛、正式批次与独立留出共用检查点、结果回写、用量和进度回调。
- `evaluators/catalog.py`、`pipeline.py`、`cell_scoring.py`：分离注册与参数校验、模型执行与产物、目标/时域评分。滚动与岭回归共用反馈执行、缺失结果补齐及评分实现；模型拟合和观测边界保持各自语义。
- `core/local_edit_events.py`：提交和账本回放共用局部编辑校验，保持幂等重试及配对比较约束。公开事件投影使用显式字段白名单，文本脱敏保持独立。
- 前端轮次视图与执行视图复用阶段状态和描述，活动候选取自服务端身份。

## 兼容边界

运行要求 DeepSeek Harness `0.2.0-rc.2`。已删除旧 scope、idle、工具注册 API 的兼容调用，以及旧扁平局部编辑事件格式；当前格式的暂停、恢复、重试、取消及迟到结果保护继续保留。原生 Harness、网关与本地执行方式均保留。

已有研究目录和当前实验进程未重启或切换。历史种子目录仍作为内容寻址的研究资产保留；这次没有对旧账本做自动迁移，也没有声称清除了全项目的全部历史协议分支。
