# 0.7.6 网页实跑与问题修复

本轮通过 DSH 网页侧栏进入工作台，真实模型预检后提交表单创建运行。训练数据使用真实 AGC 2018 AiCU 序列。没有用拦截 API、固定模型答案或创建后立即取消来代替预测验收。

## 已定位与修复

| 问题 | 处理 |
|---|---|
| Agent 修正一次输出参数后，插件仍拒绝其有效结果 | 校验修正来源、顺序与唯一成功输出，接受满足条件的同会话修正 |
| 零残差工具参数命中拟合缓存后报缺少特征 | 先验证因果基线，零残差直接使用已验证基线，其他参数仍复用拟合产物 |
| 页面进度未计入第二次独立留出推理 | 工作量和进度统一为按候选、阶段及推理副本累计，检查点去重；统计样本量不翻倍 |
| 创建接口冻结 4,096-token 预算，适配器却采用 8,192 | 共用不可变预算定义，Planner/修正 8,192，按需 Critic 2,048 |
| 原生执行故障变成候选算法失败，其他线程长时间等待 | 运行级传播故障，关闭后续准入，先取消远端任务再等待退出，保留原始原因 |
| 默认深推理耗费大量时间，配置变化没有进入运行身份 | 使用独立供应商配置做真实对照；原生模型参数、推理档位和协议参与配置指纹 |
| 研究摘要略超推荐长度导致整个运行暂停 | `concise@2` 把推荐长度改为留痕提示；原始内容保留，科学校验及硬上限仍生效 |
| 新报告格式导致历史列表无法加载 | 按记录的原版本读取清单，保留原始摘要与指纹，不自动改写历史 |

研究预设为 `ecology-researcher-v11`，预测预设为 `ecology-sample-planner-v8`。预测仍由每个时点的 Agent 自主选择是否调用工具、选哪种模型及参数，最终数值必须由 Agent 提交。

## 真实迭代证据

- 0.7.0：研究输出的合法参数修正被拒绝，修复后继续。
- 0.7.1：研究和四个候选生成成功，发现零残差工具错误，修复后继续。
- 0.7.2：270 次数值工具调用全部成功；预测最终提交前耗尽旧输出预算，运行停止。
- 0.7.3：一个完整时点的 9 项预测成功；仍出现输出额度耗尽及批量超时。不能以该结果宣称完整一代成功。
- 0.7.4 第五次运行：使用 `reasoning=minimal`，原生研究会话仍有较长推理流，停止后继续核查实际参数。
- 0.7.4 第六次运行：显式 `thinking.type=disabled` 后，搜索约 7 秒，两次研究分别约 32/29 秒；三个原生会话均没有推理增量。第二次研究报告 1,362 字符超过 1,200 的推荐长度，宿主暂停运行，促成 `concise@2` 修复。
- 0.7.6 第七次运行：`run:0b15553a-2226-4427-ac2e-86d4d2973344`，2026-09-08 01:13（北京时间）从正常网页创建，研究阶段发现 per-origin computation cost 被误判为修改样本数量；修复测量单位的识别后继续下一次实跑。本次运行已取消。

真实小型供应商参数探针分别验证了 minimal 与显式关闭推理的工具输出。探针不是科学实验，也不代替完整样本 Agent 验收。配置方式见 [独立推理配置](../../examples/dsh-native-inference.md)。

运行终止、科学门禁不通过、供应商错误和主动取消必须分别解释。即使执行链路全部通过，也不能据此声称独立 validation/final_test、跨温室泛化或稳定预测提升已经验证。
