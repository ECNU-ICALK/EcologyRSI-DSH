# 0.7.2 网页真实运行与修复

本次通过正常 DSH 网页入口，使用真实 AGC 2018 AiCU 温室数据启动自进化；未拦截 API、伪造预检或替换模型输出。策略使用 `pjlab/glm-5.2`，独立评审使用 `pjlab/kimi-k3`。

实验为一代四候选，初筛每候选 64 时点，正式每入围候选 144 时点、局部批次 72 时点，独立留出 169 时点并重复两次 Agent 推理。最大执行预算为 1,702 个候选—推理时点、15,318 个评分单元；重复推理检验输出稳定性，不增加独立观测样本数。

## 从实际运行发现的故障

1. **可选工具被描述成不能切换。** 知识目录遗漏了当前默认的基线对齐岭回归及 v4 评测器。补齐映射，并说明研究修改的是默认工具；最终预测始终由样本 Agent 自主选择工具、参数、组合方式后提交。
2. **合法格式修正被丢弃。** 研究 Agent 第一次提交缺少字段，收到明确的参数错误后纠正并被 DSH 接受；旧适配器仍丢弃整个会话。现在最多接受一次有来源证明的参数修正，要求同一回合、不同调用 ID、失败先于重试、唯一成功提交以及成功的回合结束。修正期间不能增加工具调用。未恢复的缺失结果不再伪装成网关故障反复执行整个研究。
3. **零残差与共享拟合缓存冲突。** 数值工具复用非零残差拟合缓存时，零残差输入有意省略残差特征；旧推理器仍要求这些特征。现在验证因果基线后直接返回零残差对应的基线值，正常参数继续复用相同拟合结果。
4. **执行进度低估且可能回退。** 创建预算已计两次留出推理，但运行进度仍只计一次。现在独立检查点标记推理副本，按副本的事件窗口累计；同一副本重复记录不增加计数，开始第二次推理不抹掉第一次的完成量。
5. **未评测状态显示为失败。** 尚未产生轮末决定时显示“等待评测”，不提前展示未通过结论。

## 已完成的验证

- Python 全部 117 个测试模块、1,503 项测试通过，真实数据测试启用、无跳过。
- DSH 插件 218 项测试通过，包括格式修正成功及重复成功、错误归因、越界工具调用等拒绝场景。
- 真实 AiCU 数值工具检查：6 个时点、9 个目标—时距单元、3 组残差参数，共 162 次检查通过；共用一份拟合缓存。
- 正常网页完成真实模型预检、创建、过程加载及停止；页面接口读取检查无脚本错误。停止产生的取消记录与模型失败分开看待。
