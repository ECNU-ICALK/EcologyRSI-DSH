# 界面截图清单

这些图片来自 `plugins/ecology_evolution/?demo=1` 的显式演示模式，只展示界面结构和预算口径，不连接模型 API、不启动训练，也不写入 SQLite。

| 文件 | 工作区 | 复核重点 |
|---|---|---|
| `01-run-settings.jpg` | 开始运行 | 数据集、策略模型、独立评审模型和启动条件 |
| `02-parameter-design.jpg` | 运行参数 | origin、候选、Top 2、batch、并发和预算 |
| `03-training-data.jpg` | 数据 | 字段单位、分区、快照和数据血缘 |
| `04-evolution-process.jpg` | 运行过程 | 研究、编译、评测、incumbent 和进度证据 |
| `05-candidate-evaluation.jpg` | 候选方案 | 指标、基线、约束、产物和保留结论 |
| `06-human-governance.jpg` | 人工审核 | 暂停、意见、执行收据和治理边界 |

截图尺寸统一为 `1280 × 720`。提交新界面时，先启动静态演示并逐个切换六个工作区，再更新对应图片和根 README 的说明；不要把真实令牌、路径、运行 ID 或隐藏评测数据放入截图。
