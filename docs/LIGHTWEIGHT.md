# 0.11.0 轻量化记录

## 产品范围

唯一新运行合同是 native Harness + `joint_plugin_epoch@2` + strict origin bundle @4。当前六类数值预测器、四候选比较、局部配对、轮末选择与条件复核保留。每轮基础 200 次、复核预留 100 次和 85 个唯一起点不变。

| 退出的路径 | 保留或替代 |
|---|---|
| Python 直连模型网关、独立 HTTP 重试与文本 JSON 修复 | Harness 原生角色、结构化工具、预算和错误分类 |
| Top-2、旧 quick/evidence/joint、prequential 兼容 | 当前 joint@2 固定调度 |
| 合成演示、toy/旧 rolling 生产评估 | 真实温室任务，工程 fixture 留在测试 |
| 旧数据库升级和旧事件补字段 | 新数据库；当前版本自身幂等与断点恢复 |
| 专家咨询、人工文字调参、训练资产/SFT 导出 | 自动研究与修改、可检查的科学证据 |
| 历次方案、截图、旧交付报告 | GitHub 基线；当前说明与验收记录 |

模型目录只负责配置发现、脱敏、角色权限和身份摘要，不执行推理。原生预检仍分别绑定四个角色；同一模型可以担任策略与评审。目录缺失/无效角色不再获得默认授权。

## 计量

运行 `python scripts/source_metrics.py` 重现差值。范围为 src、plugins、integrations、scripts 下的 Python、JavaScript、HTML、CSS 和 shell；排除 test/tests、dist、node_modules 和运行目录。独立比较物理行、非空行、字节，删除测试或文档不增加源码减量。

| 计量 | 0.10.11 基线 | 0.11.0 | 保留比例 |

主要减量来自删除重复网关与旧协议路径、统一 Genome 编译、精简投影与网页过程展示。当前原生工具合同、恢复、审计和科学比较保留；没有为达到精确行数目标删除这些边界。

## 升级

1. 完成或暂停旧实验，保留 0.10.11 环境及原账本。
2. 使用专用工作目录和 DSH_HOME 安装 0.11.0。
3. 配置同一模型目录、原生运行地址与令牌；创建全新的 SQLite 文件。
4. 通过网页四角色预检后创建新实验。不能将旧合同或旧账本复制为新运行。

不自动迁移实验，也不将旧版本的科学收益、真实模型成功或认证状态归因给新版本。
