# 可辨识的定向自进化设计

## 目标

让每一轮候选真正构成可解释的实验：候选共享同一参考参数、每个候选只改变一个主要参数轴、覆盖被诊断为最弱的目标/时距，并在反馈中明确标记没有变化过的参数轴。正式版本的科学门禁、同 cohort 比较和独立评审保持不变。

## 设计

1. 对兼容模型提案路径（dsh_authenticated/autonomous_model）在多候选批次启用宿主侧单轴投影。
2. 以父方案或本轮公共种子作为 shared reference；槽位按参数轴轮转，远程模型只决定该轴的值，不能同时改变其它轴。
3. 将上一轮 target_weaknesses 的首项压缩为 target_focus，传入策略模型并记录在候选设计审计中。
4. 对已有同槽位候选做参数向量去重；若模型返回重复值，宿主生成有界 witness 值。
5. 参数效果分析保留常量轴，但标记为 unidentifiable，避免把“没有变化”误判为负面或正面因果证据。
6. 轨迹和轮次投影输出 bounded search_design_audit，供网页端解释候选如何产生。
